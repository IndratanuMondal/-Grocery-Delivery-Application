# Grocery-Delivery-Application

# 📌 Project Overview

The Grocery Delivery Application is a simple yet functional web app built using HTML, CSS, and JavaScript. It simulates the core functionality of an online grocery store where users can:

- Browse available products

- Add products to the cart

- View and manage items in the shopping cart

- Proceed to checkout and see a detailed summary

This project demonstrates frontend web development skills including DOM manipulation, event handling, styling with CSS, and creating an interactive user experience without any backend.

# ✨ Features

- Product Listing – Displays grocery items (like ice-cream, bananas, carrots, tomatoes) dynamically using JavaScript.

- Add to Cart – Users can add products, and the cart count updates in real-time.

- Shopping Cart View – A cart section displays added products with prices and "Remove" buttons.

- Remove from Cart – Users can remove individual products, and totals update accordingly.

- Checkout Summary – Shows all cart items with a calculated total price in a clean UI.

- Responsive UI – Modern, responsive design using CSS grid and flexbox for mobile-friendly layout.

# 🛠️ Tech Stack

HTML5 – Structure of the app

CSS3 – Styling with a professional and modern look (cards, hover effects, buttons, responsive layout)

JavaScript (Vanilla JS) – Handles cart logic, DOM updates, and checkout summary
